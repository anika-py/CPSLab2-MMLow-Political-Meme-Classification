# CPSLab2-MMLow-Political-Meme-Classification
We propose a hierarchical multimodal framework for political meme classification using SigLIP and XLM-RoBERTa. The system predicts stance and target entity separately before combining them into fine-grained labels. Evaluated on the MMLow @ AACL-IJCNLP 2026 shared task, our approach ranked first with a final score of 0.7860.
